# 11 · 测量纪律

1. **同 boot 才直比**。同配置跨 boot，prefill 差过 1.25–1.41×（本机历史 vLLM 测过）。跨 boot 只谈数量级。
2. **丢掉第一个冷样本**。单点首包可差 1.6×。
3. **重复 3 次报中位 / max / min**，不要用单点当余量。
4. **`agg_tok/s` 含 TTFT**。对外对比写清是 decode 还是含预填充的聚合。
5. **来源分级**：A 本机命令/日志；B 别人测的（knapcio C1 表标 B）；C 写出算式；D 未核验不得往下推。
6. **时钟 latch** 会污染全部 tok/s。测前看 `nvidia-smi`。
7. 报内存看**连续采样最低** `MemAvailable`，不要单点。

knapcio README 里的 prose/code C1 是作者机、作者提示词，**未在本手册当作本机 A 级**。本机 09-29 验收以 DSH 四路与直连间隔为准，不是复刻那张 C1 表。
