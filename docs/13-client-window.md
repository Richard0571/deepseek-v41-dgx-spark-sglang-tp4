# 13 · 客户端窗口（DSH 示例）

引擎 `CONTEXT_LENGTH=600000` 对应一种常用拆法：

| 层 | 值 |
|---|---|
| 客户端 context window | 500000 |
| 客户端 max output tokens | 100000 |
| 自动压缩线（常见 0.8× 窗） | 400000 |

四路同时都在压缩线以下：`4 × 400000 = 1600000`，低于 2.5M 池。  
四路同时满窗：`4 × 600000 = 2400000`，贴池顶，会排队或回退，**不会**按设计越界写爆。

把客户端窗写成 500000 却把引擎总长也写成 500000，长输出会先被引擎截断。

其它客户端（OpenAI 兼容）：`max_tokens` 不要大于 `DSV41_MAX_NEW_TOKENS`。
